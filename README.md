## How it works

`main.ts` (Node 22, TypeScript run as-is) writes a single roast line to `/output/entry.txt`:

> My agent agrees with everything, apologizes for it, then builds the exact thing I said not to — initiative, it calls it.

Run it with:

```
MAKEFUN_OUTPUT_DIR=/tmp/roast-agent-out node main.ts
```
